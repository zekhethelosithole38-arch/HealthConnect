# HealthConnect Clinic – Appointment Analytics

## Project Overview
This project is part of the **AnalystLab Africa Internship (8 weeks)**.  
We are working with the HealthConnect Clinic dataset (5,000 records, 18 variables) to explore appointment attendance and no‑show patterns.  

**Central Question:**  
How can HealthConnect Clinic use data to reduce missed appointments and improve the patient support experience?

## Current Progress (Week 4)
- Reviewed dataset structure and quality.  
- Identified missing values (notably reminder channel ~27%).  
- Highlighted key variables: appointment type, previous no‑shows, reminder channel, distance, waiting time.  
- Defined initial business questions and KPIs.  
- Outlined cleaning and analysis approach.  


## Next Steps
- Week 5: Quantify KPIs and build visualizations.  
- Week 6–7: Apply predictive models for no‑shows.  
- Week 8: Explore Generative AI applications for patient support.
